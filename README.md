# PackMan-Insights
PackMan is a cloud-based project that tracks and visualizes daily download statistics of PYPI and NPM packages published by Microsoft. It uses Azure Functions to automate data ingestion from public APIs, stores the data in Azure Data Explorer for time-series analysis, and presents insights through interactive dashboards built in Grafana.
